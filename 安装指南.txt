========================================
  志愿者服务管理系统 - 快速安装指南
  适用：Windows 7 / Windows 10 / Windows 11
  部署方式：前端打包为 dist，由 Node 单机同时提供页面与接口（仅占用 3000 端口）
========================================

【第一步】安装 Node.js（只需做一次）
--------------------------------------
1. 打开 https://nodejs.org/
2. 下载并安装「LTS 推荐版」
3. 安装时勾选「Add to PATH」，一路下一步
4. 安装完成后，新开一个命令提示符，输入 node -v 和 npm -v，能看到版本号即成功

  Win7 用户：若安装最新 LTS 报错，可改用 Node.js 18.x 或 20.x LTS。

【第二步】安装 MySQL（只需做一次）
--------------------------------------
1. 打开 https://dev.mysql.com/downloads/mysql/
2. 下载 Windows 版 MySQL Community Server，安装
3. 安装过程中设置 root 密码，建议设为：1234（若用其他密码，见第三步及文末说明）
4. 安装时勾选「Start MySQL at System Startup」，保证开机自启

【第三步】把项目拷到目标电脑（或从 GitHub clone）
--------------------------------------
方式 A - 拷贝：将整个「volunteer-system」文件夹复制到目标电脑任意目录（如 D:\volunteer-system）。
方式 B - 从 GitHub 获取：在目标电脑上执行 git clone <仓库地址>，得到 volunteer-system 目录。

不要删掉 frontend、backend、database 等子文件夹。

  配置数据库密码（方便在其他电脑上录入）：
  项目里带有 env.default，里面是默认的 MySQL 配置（密码 1234）。在每台电脑上：
  把 env.default 复制一份，改名为 .env（或先复制再重命名）；若该电脑的 MySQL 密码不是 1234，
  用记事本打开 .env，改 MYSQL_PASSWORD=你的密码 即可。程序只读 .env，不读 env.default。

【第四步】初始化数据库（只需做一次）
--------------------------------------
任选一种方式执行 database 里的 init.sql：

  方式 A - 命令行（推荐）：
    打开命令提示符，进入项目根目录，例如：
      cd /d D:\volunteer-system
    执行（密码是 1234 时）：
      mysql -u root -p1234 < database\init.sql
    若 MySQL 密码不是 1234，把 -p1234 改成 -p你的密码

  方式 B - 图形工具（HeidiSQL / Navicat 等）：
    连接本机 MySQL（用户 root，密码 1234）→ 文件 → 运行 SQL 文件 → 选择 database\init.sql

执行成功后会创建数据库 volunteer_db 和默认管理员账号：admin / 1234。

【第五步】启动系统（部署方式）
--------------------------------------
双击项目根目录下的「启动-Node单机.bat」：

  1. 首次运行会自动安装依赖（根目录 + 前端），请等待完成
  2. 随后会自动打包前端（生成 frontend\dist），仅首次或更新前端代码后会稍慢
  3. 启动成功后，本机浏览器会打开；未打开则手动访问：http://localhost:3000
  4. 默认登录：用户名 admin，密码 1234

【第六步】打开windows defender 防火墙的3000 TCP连接
打开Windows Defender 防火墙，进入：高级设置，新建：入站规则，添加3000端口的TCP连接。
保证其他电脑可以访问部署机器(即使ping不通，也可以访问3000)。

  本机访问：http://localhost:3000
  其他电脑访问：http://本机IP:3000（例如 http://192.168.100.231:3000）

关闭系统：直接关闭弹出的黑色命令窗口即可。

========================================
  若 MySQL root 密码不是 1234
========================================
把项目里的 env.default 复制为 .env，用记事本打开 .env，把 MYSQL_PASSWORD=1234 改成你的密码，
保存后重新双击「启动-Node单机.bat」即可。

.env 里也可改：MYSQL_USER、MYSQL_HOST、MYSQL_DATABASE（一般不用改）。

========================================
  常见问题
========================================
• 提示“找不到 node”或“npm 不是内部或外部命令”
  → 先安装 Node.js 并勾选 Add to PATH，安装后重启命令提示符或电脑再试。

• 提示“数据库连接失败”或“Access denied”
  → 检查 MySQL 服务是否已启动；密码不是 1234 时在根目录建 .env 填写 MYSQL_PASSWORD。

• 端口 3000 被占用
  → 关闭占用端口的程序，或修改 backend\app.js 末尾的 listen(3000, ...) 端口号。

• Win7 下 npm install 报错
  → 使用 Node.js 18 或 20 的 LTS 版本；或以管理员身份运行命令提示符再试。

========================================
  Win11 服务器长期部署（可选阅读）
========================================
若在 Win11 服务器上长期运行，除上述步骤外请注意：

• 保持运行：当前双击「启动-Node单机.bat」后，关闭黑色窗口会停止服务。若需 7×24 运行，
  建议使用 pm2（npm i -g pm2 后，用 pm2 启动 backend\app.js）或配置为 Windows 服务，避免关窗即停。

• 远程访问：若其他电脑通过浏览器访问本机，需在 Windows 防火墙中放行端口 3000。
  本机访问地址：http://localhost:3000；其他电脑访问：http://本机IP:3000。

• 首次启动：双击 bat 后会自动执行 npm install（根目录与 frontend）、前端打包，请保持网络畅通并等待完成。
